# Deploy Amazon S3

## Introduction

Amazon Simple Storage Service (Amazon S3) is AWS's object storage service, offering virtually unlimited scalability.

In the **Smart Campus Guardian – AI Campus Incident Detection Platform** project, Amazon S3 serves as the starting point of the entire AI processing workflow. When a camera uploads an image to Amazon S3, the system automatically triggers AWS services to analyze the image and send alerts if an incident is detected.

---

## Objectives

After completing this chapter, you will be able to:

- Create a bucket for storing camera images.
- Create a bucket for hosting the React website.
- Create a bucket for storing AI reports.
- Enable bucket versioning.
- Enable server-side encryption.
- Prepare the bucket for EventBridge integration in the next chapter.

---

# Amazon S3 Architecture

Amazon S3 stores all system data and serves as the first component of the AI workflow.

When a camera uploads an image to the bucket, Amazon S3 generates an **Object Created** event, which triggers Amazon EventBridge and AWS Step Functions to start the AI processing workflow.

![Amazon S3 Architecture](/images/5-Workshop/5.5/5.5.1/s3-architecture.png)

---

## Architecture Overview

The system uses three primary buckets:

| Bucket | Purpose |
|---------|----------|
| **smart-campus-images** | Stores camera images |
| **smart-campus-frontend** | Hosts the React website |
| **smart-campus-report** | Stores AI reports and analysis results |

In this workshop, the **smart-campus-images** bucket is the most important because it will be used to trigger the AI workflow in the following chapters.

---

## Step 1: Create the Image Bucket

Sign in to the **AWS Management Console**.

Search for:

```
Amazon S3
```

Choose:

```
Create Bucket
```

Configure the bucket as follows:

Bucket Name

```
smart-campus-images
```

Region

```
Asia Pacific (Singapore)
ap-southeast-1
```

Block Public Access

```
Keep all settings enabled
```

![Create Bucket](/images/5-Workshop/5.5/5.5.2/create-bucket.png)

---

## Step 2: Create the Website Bucket

Create a new bucket named:

```
smart-campus-frontend
```

This bucket will be used to host the React website in the Dashboard chapter.

---

## Step 3: Create the AI Report Bucket

Create another bucket named:

```
smart-campus-report
```

This bucket will store:

- AI reports
- Analysis results
- Output generated by Amazon Bedrock

---

## Step 4: Enable Versioning

Within the bucket:

```
Properties
        ↓
Bucket Versioning
        ↓
Enable
```

Versioning allows you to recover data if objects are accidentally overwritten or deleted.

---

## Step 5: Enable Server-side Encryption

Within the bucket:

```
Properties
        ↓
Default Encryption
        ↓
Server-side Encryption (SSE-S3)
```

Encryption helps protect data stored in Amazon S3.

---

## Step 6: Upload a Test Image

Upload an image to verify that the bucket is working correctly.

Example:

```
fire.jpg
```

After the upload is complete, the bucket should display the newly uploaded object.

![Upload Image](/images/5-Workshop/5.5/5.5.3/upload-image.png)

---

## Best Practices

To improve security and optimize costs, follow these recommendations:

- Keep **Block Public Access** enabled.
- Enable Versioning for important buckets.
- Enable Server-side Encryption.
- Do not store sensitive information in public buckets.
- Separate buckets based on their specific purposes.
