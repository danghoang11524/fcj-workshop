# Deploy AWS Lambda

## Introduction

AWS Lambda is AWS's **Serverless Compute** service that allows you to run code without provisioning or managing servers.

In the **Smart Campus Guardian – AI Campus Incident Detection Platform** project, AWS Lambda serves as the core business logic component of the system.

Lambda receives requests from Amazon API Gateway to process the React website APIs, while also handling events generated by the AI Workflow when triggered by Amazon EventBridge.

---

## Objectives

After completing this chapter, you will be able to:

+ Create an AWS Lambda Function.
+ Configure the Runtime and IAM Role.
+ Set up Environment Variables.
+ Connect Lambda to Amazon API Gateway.
+ Prepare Lambda for the AI Workflow.
+ Send logs to Amazon CloudWatch.

# AWS Lambda Architecture

AWS Lambda is the business logic layer of the Smart Campus Guardian system.

Lambda receives requests from API Gateway or EventBridge, processes the data, and interacts with DynamoDB, SNS, SES, and AWS AI services.

![Lambda Architecture](/images/5-Workshop/5.9/5.9.1/lambda-architecture.png)

---

## Architecture Overview

Lambda operates through two main workflows.

### API Workflow

1. The React website sends a request to Amazon API Gateway.
2. API Gateway validates the JWT Token.
3. API Gateway invokes AWS Lambda.
4. Lambda executes the business logic.
5. Lambda reads from or writes data to Amazon DynamoDB.
6. The result is returned to the website.

### AI Workflow

1. Amazon EventBridge receives an event from Amazon S3.
2. EventBridge triggers AWS Step Functions.
3. Step Functions invokes AWS Lambda to preprocess the data.
4. Lambda sends the image to Amazon Rekognition.
5. The results are then processed by Amazon Bedrock.

AWS Lambda acts as the integration layer connecting services throughout the entire system.

# Deployment Steps

## Step 1: Open AWS Lambda

Sign in to the **AWS Management Console**.

Search for:

```
AWS Lambda
```

Choose:

```
Create Function
```

---

## Step 2: Create a Lambda Function

Function Name

```
SmartCampusHandler
```

Runtime

```
Python 3.12
```

Architecture

```
x86_64
```

Execution Role

```
SmartCampusLambdaRole
```

![Create Lambda](/images/5-Workshop/5.9/5.9.2/create-lambda.png)

---

## Step 3: Configure the Runtime

Memory

```
512 MB
```

Timeout

```
30 Seconds
```

Ephemeral Storage

```
512 MB
```

These settings are suitable for the processing workload in this workshop.

---

## Step 4: Configure Environment Variables

Add the following environment variables:

```
IMAGE_BUCKET

REPORT_BUCKET

INCIDENT_TABLE

SNS_TOPIC_ARN

AWS_REGION
```

Lambda uses these variables to connect to AWS services without hard-coding configuration values.

---

## Step 5: Connect API Gateway

Trigger

```
Amazon API Gateway
```

Stage

```
prod
```

API Gateway invokes the Lambda function whenever users send requests from the website.

---

## Step 6: Prepare for the AI Workflow

The Lambda function will also be invoked by AWS Step Functions in the following chapters.

Its responsibilities include:

+ Preprocess images.
+ Validate image formats.
+ Prepare data for Amazon Rekognition.
+ Store results in Amazon DynamoDB.

---

## Step 7: Test the Lambda Function

In the Lambda Console, choose:

```
Test
```

Create a test event.

Example:

```json
{
  "message": "Hello Smart Campus Guardian"
}
```

If successful, Lambda returns:

```
StatusCode: 200
```

The execution logs will also appear in Amazon CloudWatch.

## Best Practices

To ensure scalability and security, follow these recommendations:

✔ Keep Lambda functions stateless.

✔ Use Environment Variables.

✔ Never hard-code AWS Access Keys.

✔ Use IAM Roles.

✔ Send logs to Amazon CloudWatch.

✔ Configure an appropriate timeout.

✔ Reuse Lambda functions whenever possible.
